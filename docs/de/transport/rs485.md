# BiDiB über RS-485 (BiDiBus)

Dieses Dokument beschreibt die Verwendung der BiDiB-Arduino-Bibliothek mit einem RS-485-Bus, wie er von BiDiBus spezifiziert wird.

## 1. Übersicht

Der BiDiBus verwendet eine physikalische RS-485-Schicht für eine robuste Hochgeschwindigkeitskommunikation. Ein wesentliches Merkmal dieses Busses ist, dass ein Master-Knoten den Buszugriff steuert. Slave-Knoten können Daten nur senden, nachdem sie vom Master abgefragt wurden.

Diese Bibliothek stellt die Klasse `BiDiB_RS485` zur Verfügung, um die spezifischen Anforderungen des BiDiBus zu behandeln, einschließlich der Richtungsteuerung für den RS-485-Transceiver und eines Warteschlangenmechanismus für ausgehende Nachrichten.

## 2. Hardware-Setup

-   **Arduino-Board:** Jedes Arduino-kompatible Board mit einem Hardware-Seriell-Anschluss.
-   **RS-485-Transceiver:** Ein Standard-RS-485-Transceiver-Modul (z. B. basierend auf dem MAX485-Chip).
-   **Verbindungen:**
    -   Verbinden Sie den `DI` (Driver Input) des Transceivers mit dem `TX`-Pin des Arduino.
    -   Verbinden Sie den `RO` (Receiver Output) des Transceivers mit dem `RX`-Pin des Arduino.
    -   Verbinden Sie die `DE` (Driver Enable)- und `RE` (Receiver Enable)-Pins des Transceivers miteinander und mit einem digitalen Ausgangs-Pin am Arduino. Dies ist der Pin für die Richtungsteuerung.

## 3. Verwendung der `BiDiB_RS485`-Klasse

Die Klasse `BiDiB_RS485` erbt von der Standard-Klasse `BiDiB` und behandelt die busspezifische Logik automatisch.

### Initialisierung

Um die Klasse zu verwenden, müssen Sie `BiDiB_RS485.h` einbinden und eine Instanz erstellen, wobei Sie die Pin-Nummer für die Richtungsteuerung angeben.

```cpp
#include <BiDiB_RS485.h>

const int RS485_DE_PIN = 4; // Der Pin, der mit den DE/RE-Pins des Transceivers verbunden ist

BiDiB_RS485 bidib(RS485_DE_PIN);

void setup() {
  // BiDiBus arbeitet mit 500 kbaud
  Serial1.begin(500000);
  bidib.begin(Serial1);

  // ... Rest Ihres Setups
}
```

### Senden von Nachrichten

Wenn Sie eine Funktion aufrufen, die eine Nachricht sendet (z. B. `bidib.logon()`, `bidib.sendOccupancySingle()`), sendet die Klasse `BiDiB_RS485` die Nachricht nicht sofort. Stattdessen wird die Nachricht in eine Ausgangswarteschlange gestellt.

### Abfrage und Übertragung

In Ihrer Haupt-`loop()` müssen Sie sowohl `bidib.update()` als auch `bidib.handleMessages()` aufrufen.

-   `bidib.update()` liest eingehende Daten vom Bus Byte für Byte. Es erkennt automatisch die Ein-Byte-Abfrage vom Master und sendet die nächste Nachricht aus der Warteschlange. Es setzt auch alle eingehenden Nachrichten zusammen.
-   `bidib.handleMessages()` sollte nach `update()` aufgerufen werden, wenn `bidib.messageAvailable()` wahr ist. Diese Methode verarbeitet den Inhalt einer vollständig empfangenen Nachricht (z. B. um Rückrufe auszulösen).

```cpp
void loop() {
  bidib.update();
  if (bidib.messageAvailable()) {
    bidib.handleMessages();
  }

  // ... Ihre Anwendungslogik
}
```

Dies stellt sicher, dass Ihr Knoten nur sendet, wenn er die Erlaubnis vom Master hat, und entspricht dem BiDiBus-Protokoll.
